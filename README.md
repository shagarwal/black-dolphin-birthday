# Happy Birthday, Shruti & Prateik

A small static birthday card: a sealed envelope that opens into a card with the gift, two nights at Black Dolphin Inn on the Indian River, New Smyrna Beach, Florida.

Plain HTML, CSS and a few lines of JavaScript. No build step. Served with GitHub Pages.

Tests: `python3 -m http.server 8765` in this directory, then `node tests/check.js http://127.0.0.1:8765/` (needs playwright-core + Chromium).

Photographs are from [blackdolphininn.com](https://www.blackdolphininn.com/) and belong to the inn; `images/SOURCES.json` lists the original URL for each file. This page is a personal, non-commercial gift note.
